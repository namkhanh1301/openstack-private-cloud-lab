OpenStack Private Cloud Lab

A hands-on project dedicated to learning, deploying, and managing OpenStack-based private cloud infrastructure.
This repository documents practical experiments, configurations, automation scripts, and troubleshooting scenarios across key OpenStack components, including:

- Compute: Nova, KVM, and QEMU
- Networking: Neutron, Open vSwitch, OVN, VLAN, and VXLAN
- Storage: Cinder and Ceph
- Identity & Images: Keystone and Glance
- Deployment & Automation: Kolla-Ansible, Terraform, and Python
- Operations: Monitoring, troubleshooting, and infrastructure optimization

=> Project Goal: Build practical skills in designing, deploying, operating, and automating private cloud infrastructure using OpenStack.
